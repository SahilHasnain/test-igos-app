IGOS — Project Overview

Information Governance Operating System — a provider-neutral compliance platform for UK Multi-Academy Trusts.

What is IGOS?

Problem

UK schools (academies) grouped in Multi-Academy Trusts must legally comply with GDPR/UK-GDPR. Each trust needs centralised oversight of data protection cases across all its schools.

Solution

IGOS provides a single platform to manage SARs, FOIs, Data Breaches, DPIAs with strict multi-tenant isolation — each academy's data stays separate and secure.

4 Case Types

📋

SAR

Subject Access Request — someone asks "what data do you have on me?". Has a 1 calendar month deadline.

📢

FOI

Freedom of Information — public request for info. Has a 20 working days deadline.

🚨

Breach

Personal data breach — data leak/exposure. Has a 72 hours ICO notification deadline.

🔍

DPIA

Data Protection Impact Assessment — risk evaluation for new data processing activities before they go live.

Core Concept — Multi-Tenancy

MAT (Multi-Academy Trust) — e.g. "Federation of Northern Schools"
│
├── 🏫 Academy A — Riverside Academy
│   ├── SAR-2026-001  (Academy A's SAR)
│   ├── FOI-2026-003  (Academy A's FOI)
│   └── 👤 Users with Academy A access only
│
├── 🏫 Academy B — Hillcrest Academy
│   ├── BR-2026-005   (Academy B's Breach)
│   └── 👤 Users with Academy B access only
│
└── 🌐 Federation-wide
    └── DPIA-2026-001 (cross-academy assessment)

KEY RULE: Academy A's user CANNOT read, update, or even infer the existence of Academy B's data.

Two Operating Modes

Demo Mode

IGOS_DATA_MODE=demo
  • Uses in-memory JavaScript arrays
  • No database needed
  • Data resets on restart
  • For development only

Appwrite Mode

IGOS_DATA_MODE=appwrite
  • Uses real Appwrite database
  • Persistent data
  • Requires Appwrite project setup
  • For production
