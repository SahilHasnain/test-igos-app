Data Flow Traced

Follow a single request from browser to database and back.

Flow 1 — Demo Mode (Current)

Today the UI runs entirely client-side. No API calls are made.

Browser (React)
│
├─ useState(initialMatters)          ← hardcoded array from src/demo/ui-data.ts
├─ useState("DPO")                  ← fake role selector
├─ useState("Riverside Academy")    ← fake academy filter
│
└─ Renders dashboard                ← all data in browser memory

⚠ No server involved. No authentication. Data resets on page refresh.

Flow 2 — Appwrite Mode (Target)

What a real request looks like when fully connected.

① BROWSER  ─── GET /api/matters?matId=abc&type=sar ───►
   Request includes: Authorization: Bearer <jwt>

② API ROUTE  (app/api/matters/route.ts)
   │
   ├─ Extract matId, academyId, type from query params
   │
   ├─ resolveRuntimeContext(request, matId)
   │   │
   │   ├─ Demo mode: reads x-demo-user-id header
   │   └─ Appwrite mode: verifies JWT → gets Account → queries memberships table
   │       │
   │       └─ Returns: { user, membership: { matId, academyIds, roles }, correlationId }
   │
   ├─ createRuntimeMatterService()
   │   │
   │   ├─ Demo mode: returns MatterService(demoMatters, auditService)
   │   └─ Appwrite mode: returns MatterService(AppwriteMatterRepository, AuditService)
   │
   └─ service.list(context, { matId, type })

③ SERVICE  (src/services/matter-service.ts)
   │
   ├─ Authorisation check: does context.membership allow this?
   │   │
   │   └─ Checks roles → capabilities → allowed?
   │
   └─ repository.list(query)

④ REPOSITORY  (src/appwrite/matter-repository.ts)
   │
   └─ databases.listDocuments(databaseId, collectionId, [
       Query.equal("matId", "abc"),
       Query.equal("type", "sar"),
       Query.limit(100)
     ])

⑤ APPWRITE DB
   │
   └─ Returns filtered documents

   ◄──── Response flows back up the chain ────

① BROWSER  ◄── { matters: [...] } ── Renders table

Flow 3 — Creating a Matter (Write Path)

① BROWSER  ─── POST /api/matters ───►
   Body: { matId, type: "sar", title: "...", ... }

② API ROUTE
   ├─ Zod validates input schema
   ├─ resolveRuntimeContext(request, matId)     ← auth
   └─ service.create(context, input)

③ SERVICE  (MatterService.create)
   │
   ├─ Authorisation: does user have "matter:create" capability?
   │
   ├─ Generates reference: "SAR-2026-0200"
   ├─ Calculates statutoryDueAt: +1 calendar month
   │
   └─ repository.create({ ...input, reference, status: "open", version: 1 })

④ REPOSITORY  (AppwriteMatterRepository.create)
   │
   └─ databases.createDocument(dbId, tableId, ID.unique(), { ... })

⑤ SERVICE (continues)
   │
   └─ auditService.record(context, "matter.created", matter)
       │
       └─ auditRepository.create({ matId, actorUserId, action, payloadHash, ... })

① BROWSER  ◄── { matter: { id, reference, ... } } ── 201 Created

Flow 4 — Authentication

src/auth/appwrite-context.ts

Request arrives with: Authorization: Bearer <jwt>

Step 1: Create Appwrite Client with JWT
  new Client()
    .setEndpoint(env.NEXT_PUBLIC_APPWRITE_ENDPOINT)
    .setProject(env.NEXT_PUBLIC_APPWRITE_PROJECT_ID)
    .setJWT(jwt)

Step 2: Get account from JWT
  account = await new Account(client).get()
  → returns { $id, email, name }

Step 3: Find MAT membership (server-side, using admin client)
  admin.databases.listDocuments(dbId, "memberships", [
    Query.equal("matId", matId),
    Query.equal("userId", account.$id),
    Query.equal("status", "active")
  ])
  → returns { academyIds: [...], roles: [...] }

Step 4: Build RequestContext
  { user: { id, email, name },
    membership: { matId, academyIds, roles },
    correlationId: "..." }

This context is passed to EVERY service call.

Audit Trail — Append-Only + Hash Chain

Every material action creates an audit event:

AuditEvent {
  matId:         "abc"                    ← which trust
  academyId:     "def"                    ← which academy (optional)
  matterId:      "ghi"                    ← which case (optional)
  actorUserId:   "user-123"               ← who did it
  action:        "matter.created"         ← what happened
  occurredAt:    "2026-07-24T10:00:00Z"   ← when
  correlationId: "req-uuid"               ← links to request
  previousHash:  "sha256-of-prev"         ← chain link
  payloadHash:   "sha256-of-data"         ← integrity check
  metadata:      { ... }                  ← details
}

⚠ NEVER deleted or modified. Read-only for DPO, admins, auditors.
