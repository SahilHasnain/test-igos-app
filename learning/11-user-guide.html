IGOS Kaun Use Karta Hai?

👩‍💼

DPO (Data Protection Officer)

Saari data protection ki dekh-bhaal karta hai. DPIAs approve karta hai, breaches review karta hai, policies sign off karta hai. Sab academies ka data dekh sakta hai.

👩‍💻

Case Manager

Roz ka kaam karta hai — SARs kholti hai, FOIs ka jawab deti hai, breaches handle karti hai. Cases ko workflow mein aage badhati hai.

🏫

Academy Lead

Sirf apni academy ke cases dekhta hai. Doosri academy ka data nahi dekh sakta. Approve ya close nahi kar sakta — sirf trust office kar sakta hai.

4 Case Types (User Kya Kaam Karta Hai)

📋

SAR — Subject Access Request

Koi parent, pupil, ya staff member puchta hai: "Mere baare mein aapke paas kya data hai?"

Kya hota hai:

1. Intake → 2. Identity check → 3. Scope → 4. Evidence → 5. Redaction → 6. Exemptions → 7. Approval → 8. Disclose

⏰ Deadline: 1 calendar month (2 aur months se zyada extend nahi ho sakta)

📢

FOI — Freedom of Information

Koi aam insaan puchta hai: "Apne kharche, policies, faislon ke baare mein batao."

Kya hota hai:

1. Intake → 2. Validity → 3. Gathering → 4. Exemptions → 5. Public interest → 6. Approval → 7. Response

⏰ Deadline: 20 working days

🚨

Data Breach

Kuch galat ho gaya: "Personal data leak ho gayi, kho gayi, ya kisi ne dekh liya jisko nahi dekhni chahiye thi."

Kya hota hai:

1. Reported → 2. Contain → 3. Risk assess → 4. ICO decision → 5. Investigate → 6. Fix → 7. Lessons

⏰ Deadline: 72 hours — ICO ko batana hai (rok nahi sakte!)

🔍

DPIA — Data Protection Impact Assessment

Naya data processing shuru karne se pehle: "Kya risks hain aur unhe kaise kam karenge?"

Kaun kya bharta hai (multi-party):

Requester

Project description

Supplier

Security measures

Compliance

Necessity & proportionality

DPO

Risk approval

Har ek apna section submit karta hai. DPO ko har section accept karna padta hai tabhi DPIA approve ho sakta hai.

Case Detail (Side Panel)

Koi case click karo toh side panel khulta hai 4 tabs ke saath:

Tab 1: Summary

  • Case ka description
  • Case ka owner
  • Statutory deadline
  • Current workflow stage
  • Progress bar

Tab 2: Tasks

  • Baaki kaam ki checklist
  • Checkbox lagao — complete mark karo
  • jaise "Complete contextual redaction review"

Tab 3: Documents

  • Upload kiye hue evidence files
  • Upload button
  • Files Appwrite Storage mein store hoti hain

Tab 4: Audit

  • Is case pe har action ki timeline
  • Kisne kya kiya, kab kiya
  • Immutable — edit ya delete nahi ho sakta
Important buttons: "Advance" case ko next workflow stage pe le jata hai. "Add note" comment add karta hai. Kuch transitions ko approval chahiye (jaise disclosure).

User Roz Kya Karta Hai

1️⃣

Login karo

Email + password. System ko pata hota hai tumhara role kya hai aur kaunsi academies access kar sakte ho.

2️⃣

Dashboard dekho

Dekho kya zaroori hai. Kaunse cases overdue hain? Kaunsi academies ko attention chahiye?

3️⃣

Naya case khlo

"+ New matter" pe click karo. Type chuno (SAR/FOI/Breach/DPIA), details bharo, academy assign karo.

4️⃣

Case pe kaam karo

Evidence upload karo, notes add karo, tasks complete karo, workflow stages mein aage badho.

5️⃣

Approve / Close

DPO ya MAT admin approve karta hai. Case disclose/close hota hai. Audit trail complete hota hai.

Asal Duniya Ke Examples

Example 1: Parent Ki SAR

Paula Leigh ka bachcha Riverside Academy mein padhta hai. Woh saari education aur safeguarding records maangti hai. Case manager SAR kholti hai, identity verify karti hai, 128 documents gather karti hai, AI redaction review pe bhejti hai, DPO approve karta hai, records disclose hote hain. Deadline: 1 month.

Example 2: Galat Envelope Mein Letters

Hillcrest Academy mein 12 bachchon ki letters galat envelope mein daal di gayin. Breach report hota hai. Case manager incident contain karta hai, risk assess karta hai, decide karta hai ICO notification zaroori nahi (low risk), corrective actions record karta hai. Deadline: 72 hours ICO decision ke liye.

Example 3: AI Safeguarding DPIA

Riverside ek AI triage tool pilot karna chahta hai safeguarding ke liye. Use karne se pehle DPIA chahiye. Requester project description bharta hai, supplier security measures bharta hai, compliance necessity review karta hai, DPO risk approve karta hai. Multi-party: 4 logon ko submit karna padta hai tabhi approve hota hai.

Example 4: FOI — Salary Data

Koi senior staff ki salary bands maangta hai. Case manager request validate karta hai, Finance se figures gather karta hai, Section 43 exemption consider karta hai (commercial interests), public interest test karta hai, DPO approval leta hai, aur respond karta hai. Deadline: 20 working days.

User KYA NAHI Kar Sakta

✗ Academy lead doosri academy ke cases nahi dekh sakta
✗ Auditor case create ya advance nahi kar sakta
✗ Read-only user kuch nahi kar sakta — sirf dekh sakta hai
✗ Case manager approve nahi kar sakta — sirf DPO/MAT admin kar sakta hai
✗ Koi bhi audit event edit ya delete nahi kar sakta
✗ MAT A ka user MAT B ka data access nahi kar sakta
✗ Breach cases ko rok nahi sakte (72h rule strict hai)
