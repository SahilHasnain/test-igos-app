Storage Bucket (1)

Encryption: Enabled
Antivirus: Enabled
Permissions: tenant-and-academy-scoped

Permission Scoping Rules

server-only

Only the server (API routes) can read/write. Client never accesses directly. Used for: mats, notification-receipts.

tenant-scoped

Visible within a MAT but NOT scoped to a specific academy. Used for: academies, memberships, policies, processing-activities.

tenant-and-academy-scoped

Visible only within a specific academy. Used for: matters, documents, dpia-sections, audit-findings.

append-only-server

Server writes once. Never updated or deleted. Used for: audit-events.
