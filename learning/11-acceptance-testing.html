Acceptance Testing & Deployment

The complete workflow: test locally → deploy → verify → merge.

The Workflow at a Glance

1️⃣

Local Demo Mode

Click through every view and button. Verify nothing crashes. 15-20 minutes.

npm run dev
2️⃣

Deploy to Dev + Appwrite

Provision Appwrite, seed data, deploy, verify with real auth. 30-60 minutes.

npm run provision && npm run seed
3️⃣

Merge PRs Sequentially

PR #1 → #2 → #3 → #4 → #5. Only after dev passes all checks.

merge to Appsuite

Step 2 — Deploy to Dev (Appwrite Mode)

Prerequisites — what you need first:

☐ Appwrite project created (Cloud at cloud.appwrite.io or self-hosted)
☐ API key created with scopes: databases.read/write, files.read/write, users.read
☐ .env.local file created with:
NEXT_PUBLIC_APPWRITE_ENDPOINT=https://cloud.appwrite.io/v1
NEXT_PUBLIC_APPWRITE_PROJECT_ID=your-project-id
APPWRITE_API_KEY=your-api-key-v1.end
APPWRITE_DATABASE_ID=your-database-id
IGOS_DATA_MODE=demo

A. Provision Appwrite (one-time setup):

# Set your Appwrite credentials in the terminal:
export APPWRITE_ENDPOINT=https://cloud.appwrite.io/v1
export APPWRITE_PROJECT_ID=your-project-id
export APPWRITE_API_KEY=your-api-key

# Run the provisioning script:
npm run provision

# This creates:
✓ Database "igos-core"
✓ All 33 tables with correct column types
✓ Indexes as specified in schema.json
✓ "case-documents" bucket (25MB, encryption, antivirus)

B. Seed initial data (one-time setup):

# Add the database ID to your env:
export APPWRITE_DATABASE_ID=your-database-id

# Run the seed script:
npm run seed

# This creates:
✓ MAT "Rosa Federation" (slug: rosa-federation)
✓ 5 academies (Riverside, Hillcrest, Greenfield, Lakeside, Meadow)
✓ Admin user (admin@rosa-federation.igos.local / Change-Me-2026!)
✓ Admin membership with mat-admin + dpo roles

# Output shows IDs you need for .env.local:
  MAT_ID=...
  ADMIN_USER_ID=...
  ACADEMY_IDS=...

C. Update .env.local with all table IDs:

# Copy schema.json table IDs into .env.local:
APPWRITE_DATABASE_ID=your-database-id
APPWRITE_CASES_TABLE_ID=cases
APPWRITE_AUDIT_TABLE_ID=audit-events
APPWRITE_MEMBERSHIPS_TABLE_ID=memberships
APPWRITE_DOCUMENTS_TABLE_ID=documents
APPWRITE_DOCUMENTS_BUCKET_ID=case-documents
APPWRITE_WORKFLOWS_TABLE_ID=workflows
# ... (all 33 table IDs from infra/appwrite/schema.json)

# Switch to Appwrite mode:
IGOS_DATA_MODE=appwrite

D. Run in Appwrite mode and test:

npm run dev
# Go to http://localhost:3000/login
# Login with: admin@rosa-federation.igos.local / Change-Me-2026!

Step 3 — Merge PRs Sequentially

Merge order — strict sequence:

PR #1
Core Foundation — matter, workflow, audit, document, notification, deadline repos + auth context
→ Merge to Appsuite → Verify CI green → Deploy to dev
PR #2
Governance — DPIA, ROPA, policy, supplier repos + services
→ Retarget to Appsuite → Merge → Deploy to dev
PR #3
Assurance & Risk — assurance actions, audit programmes, findings, risks, evidence
→ Retarget to Appsuite → Merge → Deploy to dev
PR #4
AI Redaction — analysis, suggestions, second reviews, manifests
→ Retarget to Appsuite → Merge → Deploy to dev
PR #5
Advanced Governance — AI systems, assets, retention, records, contracts, suppliers
→ Retarget to Appsuite → Merge → Deploy to dev (final)
CRITICAL RULES:
  • Do NOT merge any PR until dev environment passes ALL acceptance checks
  • Each PR must have CI green (typecheck + tests + build) before merge
  • After each merge, redeploy to dev and re-run key acceptance checks
  • If any check fails, fix the issue before merging the next PR

Before each merge — run these checks:

# 1. Type check
npm run typecheck

# 2. All tests pass
npm test

# 3. Production build succeeds
npm run build

# 4. No security vulnerabilities
npm audit --audit-level=high

# ALL 4 must pass before merging any PR

Common Issues & Fixes

✕
"Authentication required" on login
Appwrite endpoint or project ID is wrong in .env.local. Verify with curl $APPWRITE_ENDPOINT/health
✕
"No active MAT membership was found"
Seed script hasn't been run, or membership record doesn't match your user ID. Re-run npm run seed
✕
Tables not found / columns missing
Provisioning wasn't run. Run npm run provision first, then verify table IDs in .env.local match schema.json
✕
Demo mode shows login page but no blue banner
Appwrite env vars are set but not valid. Remove NEXT_PUBLIC_APPWRITE_* from .env.local for pure demo mode
✕
CI fails on npm audit
Run npm audit fix or check if a dependency was added without --save-exact. Package-lock.json must be committed.
